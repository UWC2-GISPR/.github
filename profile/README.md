# UW Professional and Continuing Education
#### Specialization in GIS Spatial Analysis with Python and R


This Github Organization contains repositories for all of the course modules and student projects for this course and a continuing online community for the course. 



## Repositories
* The [modules](https://github.com/UWC2-GISPR/modules) repo contains the code for each module for students to follow along with. These will primarily be jupyter notebooks synched with the course JupyterHub but will also be quarto and markdown documents.
* The [projects](https://github.com/UWC2-GISPR/projects) repo contains project templates and student projects for the course.
