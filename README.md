# GISPR — GIS Spatial Analysis with Python and R

Course materials for **GIS Spatial Analysis with Python and R**, a 12-module professional development course from the
University of Washington Professional & Continuing Education (Autumn 2026).

The course is built for working GIS professionals. It extends ArcGIS Pro workflows with Python and R:
ArcPy and the ArcGIS API for Python first, then the open-source stack — GeoPandas, rasterio, xarray, sf, terra and more —
so you can script, automate, and reproduce the analyses you already do in Pro.
